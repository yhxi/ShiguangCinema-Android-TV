# Android 手机与电视发布验收

正式发布前记录 APK 版本、设备型号、Android 版本和验证结果。电视用实体遥控器，手机用触屏和系统返回手势。优先用可控制通断的测试片源验证恢复行为。

| 场景 | 操作 | 通过标准 |
| --- | --- | --- |
| 电视搜索与选集 | 搜索后用方向键移到第二屏，等待慢源补齐。打开详情，选一集播放。退出播放后再退出详情。 | 补齐结果时焦点留在原卡片。退出播放回到原选集，退出详情恢复原结果和列表位置。各步可见焦点高亮。 |
| 电视最近观看 | 在首页横向移动到首屏外的记录并续播。结束后再从全部历史重复。 | 回到相同页面，原作品仍被选中且可见。历史显示最新进度。 |
| 儿童与家长操作 | 在儿童乐园横向浏览。进入和返回「全部」。打开家长设置，测试取消验证、关闭设置和保存新额度。 | 关闭后焦点回到打开弹窗的按钮，额度即时更新。返回「全部」的上一级时保留原分区的横向位置。 |
| 手机返回 | 用触屏打开搜索结果、详情和选集。播放时切换横竖屏，用边缘返回手势退出。 | 依次回到详情和同一批搜索结果。首页才触发退出确认。 |
| 点播换源 | 让当前线路中断，准备一个无画面或启动过慢的候选，以及一个同集可播放的候选。再分别测试取消和全部失败。 | 只在候选实际出画且进度开始前进后显示换源成功。音频媒体以正常播放为准。换源后还是同一集，失败或取消回到原来源和播放位置。记录点击到首帧耗时。 |
| 直播换台 | 导入同频道多线路，令第一条失败、第二条可播。再次进入频道，然后令第二条失败。 | 首次自动回退出画。再次进入优先尝试第二条，第二条失败后其余线路仍可尝试。断网与线路耗尽有明确提示，可手动重试。 |
| 搜索失败源 | 用一条可匹配的片源和一条临时不可用的片源搜索，恢复失效片源后点击「重试失败源」。 | 首批结果显示后可看到查询覆盖状态。重试仅请求失败源，原结果和选中位置保留。测试所有源失败和无匹配作品两种情况。 |
| 备份迁移 | 在有历史、收藏、停用片源、续播进度和跳过标记的设备导出，然后在另一台设备连接服务端并恢复两次。另试损坏的文件。 | 合并结果无重复，停用状态和标记可恢复，文件没有服务器登录密码或会话字段。损坏文件显示失败，已有数据没有变化。 |

电脑连上 Android 设备后可用 ADB 重放方向键、确认和返回。以下命令在当前界面依次发送右、下、确认和返回，最后读取界面结构供检查焦点。每一步也可单独执行，并用电视画面核对滚动位置和高亮。

```powershell
adb devices -l
adb shell input keyevent KEYCODE_DPAD_RIGHT
adb shell input keyevent KEYCODE_DPAD_DOWN
adb shell input keyevent KEYCODE_DPAD_CENTER
adb shell input keyevent KEYCODE_BACK
adb shell uiautomator dump /sdcard/shiguang-window.xml
adb shell cat /sdcard/shiguang-window.xml
```
